这 5 类本质上是**"输入→输出"的映射方式不同**，区别在于输出是什么、以及是否涉及序列对齐。结合表里具体模型说明：

## 1. Prediction（分类/回归）
最常规的任务：**一个窗口 → 一个标签/数值**。输入是固定长度的脑电片段，输出维度就是 `n_outputs`（如 4 类运动想象）。

- 分类：输出是离散类别（softmax）
- 回归：输出是连续数值

表里绝大多数模型属于此类，如 [EEGNet](file:///Users/usst_ziyi/Programs/trae/DeepL/braindecode-lightning/.venv/lib/python3.14/site-packages/braindecode/models/eegnet.py)、Deep4Net、EEGConformer（`n_outputs=4`）。它的核心假设：**整段窗口只有一个标签**。

## 2. Embedding（特征提取）
**窗口 → 一个通用的特征向量**，而不是任务标签。输出是一个固定长度的表征（embedding），不直接给分类结果，而是作为特征供下游任务使用（迁移学习、检索、EEG2Text、自监督预训练等）。

表里标注为 `Prediction, Embedding` 或纯 `Embedding` 的都是"能当特征提取器用"的模型，如 BENDR、Labram、SignalJEPA、CBraMod。比如 BIOT 预训练后，拿它的隐层向量去接一个小分类头，就转成 Prediction 用。

## 3. Classification
和 Prediction 的"分类"含义基本重合，**区别只在任务表达上**：

- Prediction 是通用说法（含分类/回归）
- Classification 是明确强调"离散类别判别"

表里标 Classification 的多是较新的模型，如 TCFormer、EEGDINO、STEEGFormer。其中 EEGDINO 是自监督预训练（本质产出特征），但用法被明确框定为分类任务。所以你可以把它当作"这个模型主要就是拿来分类的"。

## 4. CTC Sequence（序列到序列）
处理**输入比输出长、且帧与标签之间无对齐关系**的任务。模型对输入的每个时间步输出一个字符/符号的概率分布（含空白符 `blank`），用 CTC 损失自动对齐，最终解码出标签序列。

对应表里两个 sEMG 模型：
- [MetaNeuromotorHand](file:///Users/usst_ziyi/Programs/trae/DeepL/braindecode-lightning/.venv/lib/python3.14/site-packages/braindecode/models/meta_neuromotor.py)：手写解码，`n_outputs=100`（字符集含空白）
- EMG2QwertyNet：打字解码，`n_outputs=99`

和 Prediction 的区别：Prediction 是"整段→一个标签"，CTC 是"逐帧→标签序列"，且不需要人为切分每个字符的起止。

## 5. Event Detection（事件检测）
在**一段连续长信号里定位事件发生的位置**，而不是给整段打一个标签。输入窗口很长（DANCE 是 `n_times=6400`，32 秒），输出通常包含事件类别 + 时间位置（框/时间戳），类似目标检测之于图像。

和 Classification 的区别：Classification 一个窗口一个标签；Event Detection 一个窗口里可以出现**多个、可重复、带位置**的事件。

## 一句话总结

| 类型 | 输出 | 核心假设 |
|------|------|---------|
| Prediction | 一个标签/数值 | 整段窗口对应一个结果 |
| Embedding | 一个特征向量 | 提取通用表征供下游使用 |
| Classification | 一个离散类别 | 同 Prediction 分类，强调判别 |
| CTC Sequence | 标签序列 | 输入长、逐帧输出、对齐未知 |
| Event Detection | 多个事件+位置 | 窗口内含多个待定位事件 |

对你的运动想象四分类项目来说，只涉及最前面的 **Prediction/Classification**（EEGNet、Deep4Net、EEGConformer 都是这种），表里其余几类主要用于判断某个模型是否匹配你的任务类型。
